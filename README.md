# Interactive Audio Visualizer

Interactive Audio Visualizer is a small web-based experiment focused on making audio behavior more visual, tactile, and intuitive.

The project is designed as a learning platform where users can interact with a simulated string-based instrument and observe how resonance, pitch, and frequency modulation affect an audio source in real time.

While I usually prefer physically grounded systems and more exact implementations, some creative compromises were necessary here to keep the demo responsive and usable across desktop browsers, mobile devices, and JavaScript-based web environments.

## Purpose

This project started as an idea for a small interactive feature on my main landing page. As the concept grew, it became clear that it made more sense as its own public repository rather than being buried inside a larger website.

It is now being developed as a standalone demo and experimentation space for interactive audio visualization and browser-based sound interaction.
