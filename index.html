What this demo-project is actually doing

Incoming audio is not being perfectly repitched like a studio-grade 'spectral shifter', it is being passed through a tunable string/body resonance model so the selected string and finger position reshape the tone in a way that still feels intuitive.

This demo-project favors believable interaction over fake DSP ideas. The selected string's note controls a resonance model with harmonic emphasis, damping, and body coloration. The goal is to make this browser demo is to provide a way to intuitively and visually assist learning.
